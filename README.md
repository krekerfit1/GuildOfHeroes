## Главный класс проекта Game



Почему этот объект нужен программе:
Класс Game хранит еденицу обьекта в каталоге.Еслт его не использовать то что усложнило бы добавление новых тайтлов и поиск. Объект объединяет все характеристики конкретной игры в одну структурированную сущность.

Какие данные хранит объект:

* Title — название игры;
* Genre — жанр игры;
* ReleaseYear — год выпуска;
* Rating — пользовательский рейтинг;
* HoursPlayed — количество наигранных часов;
* IsInstalled — статус установки игры на устройстве.

Какие значения задаются через конструктор:
Через конструктор передаются неизменяемые или ключевые атрибуты карточки игры: название, жанр, год выхода и рейтинг, наигранные часы и статус установки игры.
