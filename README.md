## Самостоятельная работа

- **Добавленное действие:** метод `AddHours` увеличивает количество наигранных часов .
- **Что получает параметр:** целое число `hours` — количество часов, проведённых в игре за сессию.
- **Проверка:** при передаче `hours <= 0` останется прежнее наигранное время.

### Поведение главного класса

Метод 1: `AddHours`
Что делает: прибавляет положительное число часов к полю `Hours_Played` (проверка `<= 0`).

Метод 2: `ChangeRating`
Что делает: обновляет поле `Rating` новой оценкой, если она входит в допустимый диапазон от `0` до `10`.

Метод 3: `IsCompleted`
Что возвращает: `true`, если наиграно хотябы 50 часов, иначе `false`.

Почему эти действия относятся именно к этому классу?:

Учёт наигранного времени, выставление пользовательской оценки и проверка статуса прохождения — это операции над карточкой конкретной игры в библиотеке юзера.
